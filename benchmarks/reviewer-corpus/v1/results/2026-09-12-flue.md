## Gate definition

The release gate requires the complete corpus with three trials per case,
grade A, an average score of at least 0.900, zero infrastructure errors, and
exact detection of every
security-blocker golden, at least 95% clean-diff accuracy, and stable verdicts
across all three trial rounds. DeepEval is intentionally excluded from this
baseline until the deterministic gate is stable.

## Method and runtime evidence

This single run invoked the actual Flue reviewer CLI against the configured live model gateway, sequentially over all 20 cases for three rounds. It ran on September 11 in Vancouver, from `2026-09-12T00:55:22Z` to `2026-09-12T01:08:03Z` UTC. No trials were discarded or rerun to improve the score.

```sh
agent-eval eval-review-agent \
  --command "/usr/local/bin/node /opt/reviewer/dist/cli.js" \
  --corpus /app/benchmarks/reviewer-corpus/v1/corpus.yaml \
  --trials 3 --no-self-correct --no-judge --timeout 120 \
  --out "$REPORT_PATH"
```

The evaluator used its unchanged acceptance threshold of 0.6. Every result has exactly one evaluator attempt and no judge result. The target's existing bounded HTTP/format retry policy was unchanged; internal retries are not independent trials. The public `model-gateway/reviewer` alias identifies the runtime route, not a reproducible public model version. The underlying private deployment configuration and credentials are excluded.

## Failure analysis and limits

The `path-traversal` trials 1 and 2 and `shell-injection` trial 3 emitted blocking security findings, but their source lines did not match the exact goldens. They remain failures under the declared line-sensitive metric; 85.7% is exact golden-match recall, not proof that those three security risks went unrecognized. The `swallowed-error` second trial returned no findings and did not block. These three cases also failed the stability requirement. All seven clean cases were correct in every round.

This known regression corpus is not a held-out or representative sample of production pull requests. The result does not qualify the reviewer as a sole merge gate. An A aggregate grade does not override the failed release gate. The previous September 3 baseline used a different reviewer/model and permitted correction, so it is historical context rather than a controlled comparison.
