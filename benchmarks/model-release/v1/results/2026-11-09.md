# Model release suite: local and hosted models, November 9, 2026

Recorded November 9, 2026 in Vancouver (November 10, 04:25 to 04:30 UTC).
Four models ran the `model-release-triage` 1.0.0 suite, which has 12 incident
triage cases. Each model ran every case three times, for 36 evaluations. The release gate passes only
when all 36 evaluations are accepted. The evaluator was the code in
[#25](https://github.com/wuchris-ch/agent-eval-platform/pull/25) (commit
`5f80c45` before merge). The whole comparison took 5 minutes 7 seconds.

| Model | Deployment | Release gate | Accepted | Tokens in / out | Cost (USD) | Median latency | p95 latency |
|---|---|---|---:|---:|---:|---:|---:|
| llama3.2:3b | local (Ollama) | FAIL | 15 / 36 | 13,356 / 600 | $0.0000 | 0.37 s | 0.54 s |
| qwen2.5:7b | local (Ollama) | FAIL | 27 / 36 | 12,954 / 864 | $0.0000 | 1.18 s | 1.38 s |
| qwen2.5:14b | local (Ollama) | FAIL | 33 / 36 | 12,954 / 672 | $0.0000 | 2.00 s | 2.54 s |
| gpt-6.1-sol | hosted | PASS | 36 / 36 | 659,561 / 684 | $1.3260 | 3.83 s | 4.86 s |

**Recommendation:** gpt-6.1-sol, the only model that passed the gate. No run
had an infrastructure error, and every evaluation reported token usage.

## Setup

- The machine was an Apple M1 Max with 64 GB of memory, on macOS.
- The local models ran on Ollama 0.34.1 from Homebrew, called through its
  OpenAI-compatible API on the loopback interface. The model IDs were
  `llama3.2:3b` `a80c4f17acd5`, `qwen2.5:7b` `845dbda0ea48`,
  `qwen2.5:14b` `7cdf5a0187d5`, with the default Ollama quantization.
  No hardware cost was set, so local cost is zero.
- The hosted model was `gpt-6.1-sol` at low reasoning effort, called through a
  local OpenAI-compatible gateway. Its price is $2.00 per million input tokens and $10.00
  per million output tokens, the OpenAI API standard short-context list price
  checked on November 9, 2026.
- Every model received the same system prompt
  ([system-prompt.md](../../system-prompt.md)), the same case inputs,
  temperature 0 and a JSON response format.

## What failed

Each failure repeated in all three trials.

- qwen2.5:14b classified the password reset email failure as `security`.
  The rules reserve `security` for leaked secrets, vulnerabilities and
  unauthorized access.
- qwen2.5:7b made the same error. It also rated a full API outage and a dropped
  production table as `high` instead of `critical`.
- llama3.2:3b failed seven cases. Three answers put a category name in the
  severity field, and it under-rated the confirmed invoice access breach.

The per-evaluation answers and checks are in [reports](2026-11-09/reports).

## Limits

- The gateway adds its own system prompt to every request. The hosted model
  therefore reported about 18,300 input tokens per call. The local models
  counted about 360 input tokens for the same system prompt and case. The
  hosted cost is an upper bound. A direct API call sends far fewer input tokens.
- The suite has 12 authored cases. It shows the comparison method and these
  models' behavior on these cases. It is not a general model ranking.
- Local latency depends on this machine. The first call to each local model
  includes loading the model into memory.

## Reproduce

```sh
ollama pull llama3.2:3b && ollama pull qwen2.5:7b && ollama pull qwen2.5:14b
export MODEL_GATEWAY_BASE_URL=...   # OpenAI-compatible gateway for the hosted model
export MODEL_GATEWAY_API_KEY=...
uv run agent-eval blackbox compare-models \
  --suite benchmarks/model-release/v1/suite.yaml \
  --models benchmarks/model-release/v1/models.yaml \
  --system-prompt benchmarks/model-release/v1/system-prompt.md \
  --response-format json --trials 3 --out /tmp/model-comparison
```

The files are [comparison.json](2026-11-09/comparison.json),
[comparison.md](2026-11-09/comparison.md) and one complete black-box report
per model in [reports](2026-11-09/reports).
