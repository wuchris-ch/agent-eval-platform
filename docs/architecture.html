Architecture

How a trial becomes a verdict

Four views of one system. Hover or tap any box to trace what feeds it and what it feeds.

Reading this view

  1. The four inputs along the top are versioned. The target only sees its task; expected findings and release thresholds stay with the evaluator.
  2. Each trial binds its exact input by hash, runs the target under a timeout in an allowlisted environment, then verifies the output with checks the target cannot change.
  3. A valid rejection earns one critique-guided retry. The first result is kept and reported separately.
  4. The release gate turns the whole cohort into PASS or FAIL and writes an auditable JSON report. Telemetry leaves through a collector that strips content.
  1. The agent edits a workspace inside its own pod, and its provider log streams out as JSONL while it works.
  2. After exit or timeout, leftover processes are stopped. The workspace is copied only after three clean process scans.
  3. Three independent sources examine the result: usage and timing, hidden tests run from a separate evaluator pod over one TCP port, and static inspection of the workspace.
  4. The acceptance policy needs all of them. Missing evidence fails closed and is still recorded as an explicit outcome.
  1. Admission comes before any side effect: no cluster setup, image work, credential loading or model call until the request, policy and registered identities pass.
  2. An admitted request gets a private snapshot of the exact task tree, used for this run only.
  3. Right before execution, the task, image, recipe and scanner identities are recomputed. Any mismatch stops the run.
  4. Both gates record their denials, so refused runs stay visible.
  1. results.json is the canonical record of a run. Missing values are explicit nulls, so a gap never reads as a zero.
  2. metrics.db is a query projection over completed runs, used by compare and report.
  3. verify-run recomputes the record and cross-checks it.
  4. OpenTelemetry export is optional, content-minimized and lossy, so it never stands in for the record.
